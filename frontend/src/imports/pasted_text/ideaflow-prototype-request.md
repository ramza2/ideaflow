# IdeaFlow 웹 애플리케이션 디자인 및 Vite React 프로토타입 생성 요청

## 1. 프로젝트 개요

**프로젝트명:** IdeaFlow

IdeaFlow는 사용자가 떠오른 아이디어를 자연어로 자유롭게 입력하면 LLM이 내용을 구조화하고, 필요한 경우 웹 검색으로 외부 정보를 보완한 뒤 사용자가 검토하여 데이터베이스에 등록하는 다중 사용자 기반 아이디어 관리 서비스입니다.

관리 대상은 AI·소프트웨어 아이디어에 한정하지 않습니다.

다음과 같은 모든 종류의 아이디어를 관리합니다.

* 제품 및 서비스
* 기술 및 연구개발
* 사업 및 마케팅
* 업무 개선
* 조직 운영
* 교육 및 콘텐츠
* 생활 개선
* 개인 프로젝트
* 기타 자유 주제

서비스의 핵심 사용자 흐름은 다음과 같습니다.

```text
자연어 아이디어 입력
→ LLM 구조화
→ 부족한 정보 판단
→ 필요 시 웹 검색 승인
→ 등록 초안 생성
→ 사용자가 검토·수정
→ 아이디어 등록
→ 검토·협업
→ 검증·실행 단계로 발전
```

# 2. 생성 결과 요구사항

Vite, React, TypeScript 기반의 실제 실행 가능한 프론트엔드 프로토타입을 생성해 주세요.

필수 조건:

* Vite
* React
* TypeScript
* React Router
* 데스크톱 우선 반응형 웹
* 공통 Layout과 컴포넌트 분리
* 화면별 Route 분리
* Mock 데이터 별도 파일 관리
* 실제 Backend API 호출 제외
* 실제 LLM 호출 제외
* 실제 웹 검색 제외
* 실제 인증 처리 제외
* 화면 이동과 주요 인터랙션은 Mock으로 동작
* 모든 화면을 하나의 `App.tsx`에 작성하지 말 것
* 임의로 Firebase, Supabase, 결제 기능을 추가하지 말 것

생성한 소스는 이후 실제 프로젝트의 `frontend` 폴더에 복사하여 Backend API와 연결할 예정입니다.

따라서 Mock 데이터와 UI 로직이 실제 API 연동 코드로 쉽게 교체될 수 있어야 합니다.

# 3. 디자인 방향

업무용 생산성 서비스이지만 지나치게 딱딱하지 않은 현대적인 SaaS 디자인을 적용해 주세요.

참고 분위기:

* Linear
* Notion
* Slack
* 현대적인 B2B SaaS Dashboard

디자인 원칙:

* 밝은 배경
* 명확한 정보 계층
* 적당한 여백
* 부드러운 카드와 경계선
* 과도한 그라데이션과 장식 지양
* 아이디어 작성과 검토에 집중
* AI 기능은 강조하되 전체 서비스가 AI 전용처럼 보이지 않도록 구성
* 모든 화면을 보라색 AI 테마로 만들지 말 것
* 접근성과 가독성을 우선할 것

색상 역할:

* Primary: 주요 버튼과 선택 상태
* AI Accent: AI 정리·생성·추천 기능
* Success: 완료와 연결 정상
* Warning: 검토 필요와 정보 불확실
* Danger: 삭제와 오류
* Neutral: 배경, 경계선, 보조 텍스트
